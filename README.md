# BBM – Blotan Base Management (Prototype Walnut)

Prototype front-end untuk demonstrasi digitalisasi penjadwalan dan pengelolaan operasional.

## Menjalankan di VS Code
1. Ekstrak ZIP ini.
2. Buka folder `BBM_Prototype_Walnut` di Visual Studio Code.
3. Buka `index.html`.
4. Klik kanan → **Open with Live Server** (jika ekstensi Live Server tersedia), atau buka file `index.html` langsung di browser.
5. Tidak membutuhkan npm, framework, atau database untuk demo awal.

## Fitur demo
- Data awal simulasi.
- Tambah, edit, dan hapus data pada modul operasional.
- Pencatatan jadwal, target selesai, penanggung jawab, dan progres.
- Peringatan jadwal terlambat dan stok di bawah minimum.
- Ringkasan laporan dan cetak laporan.
- Penyimpanan data pada `localStorage` browser.

## Batasan prototype
Ini adalah prototype front-end untuk demonstrasi, bukan sistem produksi final.
- Belum ada backend, database terpusat, login, atau hak akses multi-user.
- Data yang tampil adalah data dummy, bukan data aktual perusahaan.
- Penjadwalan dimasukkan manual; belum ada optimasi kapasitas mesin/tenaga kerja.
- Integrasi lintas modul masih berupa simulasi di browser.
